# 更好的网络搜索 · 新手引导

> 这个插件**不注册也能用**。下面三步是"想让它更快更稳"的做法，全过程大概 3 分钟，不需要信用卡。

## 一、三步接入（注册 → 粘贴 → 完成）

### 第 1 步：注册并拿到密钥

打开这个网址（国内可以直连打开，实测几百毫秒就能开，不用挂代理）：

https://dashboard.exa.ai/api-keys

- 登录方式请选 **Continue with Email**。页面上还有 **Continue with Google**，但国内 Google 用不了，别在它上面浪费时间。
- 邮箱用 **QQ 邮箱 / 163 邮箱都可以**。等了一会儿没收到信，先去**垃圾邮件**里翻一下。
- 登录后点 **Create API Key**，生成一串密钥，**整段复制**下来。页面上写的 "API Key" 就是这里说的"密钥"。

注册完邮箱，Exa 会连着问你三个问题。照下面选就能进控制台，**选错了也不影响密钥、不影响额度**：

| 它问的问题 | 怎么选 |
| --- | --- |
| What are you coding with? | 随便选一个 |
| What integration should the prompt generate? | 选 **mcp** |
| What are you building? | 选 **Web search tool** |

这三题只决定它给你看哪一种接入引导；本插件调的是同一个端点，跟额度、速度都无关。

### 第 2 步：把密钥粘进面板的输入框

在插件面板的引导里，点进输入框，直接 `Ctrl+V` 整段粘贴，前后不要留空格。

- 保存以后，面板上**只显示后四位**（形如 `exa****9b2c`），不会再显示完整内容。
- 明文不会留在面板里，也不会写进日志；插件请求 Exa 时把密钥放在请求头里，不放进网址。

### 第 3 步：点「保存并使用」

插件会立刻用它搜一次来验货：

- **成功**：以后优先走 Exa，结果更快更稳。
- **没验通过**：面板会直接告诉你原因，并且**自动改用免费额度**，不会因此就搜不到东西。

之后随时能在面板里：查看每把密钥的掩码与状态、重测、移除单把、再加一把，或者点「重新引导」再看一遍这三步。

### 一把的额度不够用？再加几把

一个 Exa 账号每月 $10（约 1400 次搜索）。不够就在同一个邮箱注册页再开一个账号（换个邮箱），拿到第二把密钥，在面板「密钥管理」里点**再加一把**贴进去。

- 密钥是**一个环**：一次搜索只用一把，从"上一把成功的那把"开始；这把报错就顺延下一把，走到列表末尾再绕回开头。你完全感觉不到中间失败过。
- 没有倒计时、没有"歇到几点"：一把坏钥匙要等其它每把都轮过一遍才会再被试一次，**这个循环本身就是重试节奏**。账号多几个，转一圈的时间自然就更长。
- **重启软件或插件都不会把循环打回原点**：转到哪一把了就按那把的指纹记下来，重启后从同一把继续，不会又从头去撞已经用完的那几把。
- 整池都失败时：默认**直接改用其它搜索来源**（免 Key 的 anysearch、必应等），照样能搜到东西。想要"再用一次公共匿名档试一下"，把「密钥管理」里那个开关打开就行——默认是关的，因为钥匙全见底时公共匿名档通常也不通，不如把时间省给下一个来源。
- 如果 Exa 整个连不上（超时、网络不通，跟你的钥匙没关系）：插件不会拿后面几把钥匙去撞同一条死网络，而是让 Exa 歇一会儿、这一次直接用别的来源。所以偶尔看到"这次是必应答的"，不代表密钥坏了。
- 面板不显示"还剩多少刀"——Exa 只提供已花费金额、不提供余额，而且那个接口要按团队找客服开通。所以状态一律来自密钥实际的回答：能用 / 额度用完 / 没验通过 / 还没测。

## 二、不注册会怎样

**照样能用。** 面板首屏点「先体验（不用注册）」就能直接开始搜，插件会走公共的免费搜索来源。

差别只有这些：

- 更慢一点；
- 限额更低；
- 偶尔抽风（某些来源近期对陌生访问管得比较严）。

额度账（注册之后）：

- 注册送 **$20**，之后**每月刷新 $10**；
- 搜索一次大约 **$0.007**，所以 **每月约 1400 次、平均每天 47 次**；
- **不需要绑信用卡，用完不会自动扣钱**：超出后 Exa 返回 402，插件会自动切到别的搜索来源，你只会觉得慢一点。

## 三、常见问题

### 1. 搜不到结果怎么办？

按这个顺序看，不用改任何配置文件：

1. 先看「最近一次搜索」这张卡（点「刷新面板」拿到最新的）：它写明刚才是哪一路答的、几条、多久、依次试过哪几路，失败时还会带上当时回给对话的那句话。这张卡是空的（"这里还没有搜索记录"）说明那次请求根本没走到插件，问题在宿主侧。
2. 再看面板顶部：插件是不是已经启动了。启动中时按钮点不动，等它跑完再点「刷新面板」。
3. 点「网络自检」（会真的搜一次，消耗 1 次额度），它会挨个试一遍各个搜索来源，并给一句中文结论。
4. 看「现在会用到哪些搜索来源」：列表为空说明暂时没找到可用的来源，等插件启动完成后刷新。
5. 密钥状态显示「没验通过」：重新复制一次密钥再点「保存并使用」（常见原因是粘贴时带了空格、或者复制到了别人的密钥）。显示「额度用完」不是坏了，是这个账号的 $10 用完了：点「再加一把」补一个账号，或者点「重测全部」立刻再验一次；什么都不做也行，转一圈会轮到它。
6. 某一次特别慢：不用管，前面的来源不行时插件会自动换下一个来源重试。

### 2. 国内要不要开代理？

**不用为了这个插件特意开代理。** 主用的 Exa、备用来源 anysearch、以及必应，国内直连都能到（实测 0.2–0.5 秒握手完成）。

- 面板显示"代理设置：auto"时，它会跟随你的系统/环境代理，不用手填。
- **duckduckgo 只有在检测到你在用代理时才会被启用**：国内直连它基本搜不到东西，所以没代理时你不会在列表里看到它，这是正常的。
- 如果你用 TUN 模式、拿到的是 `198.18.x.x` 这类虚拟地址：面板里的「代理虚拟地址放行」保持开着就能抓到网页正文，不需要你去懂网段配置。

### 3. 额度用完会扣钱吗？

**不会。** 注册不要信用卡、也不绑卡，所以不存在自动扣费。用完之后 Exa 返回 402，插件本次会自动改用免费额度继续搜，只是慢一点。

想让面板显示当前额度还剩多少，请到 Exa 自己的控制台看：https://dashboard.exa.ai

### 4. 怎么停用 / 开回宿主内置的『网络搜索』？

到宿主的**「插件中心」**里操作 `web_search`（本插件的面板只显示它在不在跑，不替你开关）。

- 停用之后，对话里的搜索就只走本插件；再打开它，内置的网络搜索重新运行。
- 建议顺手确认「开机自启」也是关的：在插件中心停用会一起做掉，重启后不会自己爬起来。
- 面板这张卡的「重新检查」按钮读的是宿主的状态。提示"状态读不到"时，以插件中心里看到的为准。
- **为什么改成手动**：v0.9.7 之前这个开关是插件替你去按宿主的本地管理接口，而宿主正在重载插件列表时那一按常常 8 秒以上才回话，回话之前插件分不清"没生效"还是"没答上"——真机 19 次启动记录的"失败"没有一次是真失败，全是已经做成的事被报成错误。改成后台自动核对之后仍不彻底（核对成功一次就不再看了，内置被启回来就没人管）。所以整条写入路撤掉，只留读：手动停用一次就长期有效，也更稳。
